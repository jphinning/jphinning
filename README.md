# Olá, sou João Pedro Hinning 👋

Engenheiro com foco em **Firmware**, **IoT** e **Inteligência Artificial aplicada a hardware**. Trabalho na interseção entre software embarcado e machine learning — do sensor ao modelo, do FPGA à inferência.

## 🔧 O que eu faço

- **Firmware & IoT** — desenvolvimento embarcado com ESP32 e ESP-IDF (C), comunicação Wi-Fi/MQTT, periféricos (SPI, I2C, UART), ambientes reprodutíveis com Dev Container
- **Deep Learning** — redes neurais convolucionais com PyTorch, modelagem comportamental de amplificadores de potência RF, co-simulação software/hardware
- **Hardware Digital** — implementação de CNNs em VHDL para FPGA, unidades MAC, LUTs de ativação, validação com vetores de co-simulação
- **Modelagem de Sistemas RF** — predição de saída de PAs com Memory Polynomial Model e regressão múltipla (AM-AM, AM-PM, DPD)
